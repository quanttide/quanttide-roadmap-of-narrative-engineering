# E1 — L1 任务精度与方法验证

## 假设

1. L1 分类的 7 项任务（逻辑断裂检测、事实/名称矛盾、叙述时间线错乱、结构完整性缺失、语法/拼写错误、关键词重复密度、格式/排版合规）的 AI-人类一致率 ≥ 85%（κ ≥ 0.85）。
2. 对"逻辑断裂检测"子任务，RST 辅助方法的召回率显著高于纯规则匹配方法（p < 0.05，单侧），且精确率不低于规则匹配。

## 材料

职场言情系列 14 篇成稿，每篇约 500–1500 字。所有篇目同时用于基础验证和 RST 专项验证。

## 评审者

招募 3 位具备语言学背景的评审者，同时满足以下两类标注能力：
- 通用 L1 分类标注（对 14 篇执行全部 7 项任务的二值判断）
- RST 关系标注（对 14 篇中"逻辑断裂检测"任务建立核-卫星关系树）

评审者独立标注，互不协商。

## 流程

实验分为两个并行模块：

### 模块 A — L1 基础验证

1. **AI 评审**：对 14 篇逐篇执行 7 项 L1 任务，输出二值判断（通过/问题位置）或（存在/缺失）
2. **人类评审**：3 位评审者对同一 14 篇执行相同 7 项任务，独立标注
3. **汇总**：逐篇、逐项、逐人汇总判断结果

### 模块 B — 逻辑断裂 RST 方法对比

本模块嵌套在模块 A 中，聚焦"逻辑断裂检测"这一子任务：

1. **RST 标注**：对全部 14 篇进行 RST 关系标注（核-卫星结构关系，包括证据-主张、背景-叙述、因果、时序、对比等）
2. **对照组**：现有规则匹配方法（关键词/连接词触发）
3. **实验组**：RST 辅助方法（检测 RST 关系链中的缺失或冲突，如"标记为因果但缺乏前提"）
4. **地面真值**：以 3 位评审者在模块 A 中标注的逻辑断裂位置为基础，取多数判断为真值。如有争议，以 2 位语言学背景评审者（从 3 位中指定）的独立复标注裁决

## 变量

### 模块 A

- 自变量：任务类型（7 个水平）、文本篇目（14 个水平）
- 因变量：一致率（AI vs 人类多数判断，逐项计算 Cohen's κ）

### 模块 B

- 自变量：检测方法（规则匹配 vs RST 辅助，2 个水平）
- 因变量：
  - 召回率（正确检测的断裂数 / 地面真值断裂总数）
  - 精确率（检测为断裂的位置中实际断裂的比例）
  - 人类认可率（检测出的断裂中人类评审认可的比例）

## 分析方案

1. 对每项 L1 任务，计算 AI 判断与 3 位人类评审多数判断的 Cohen's κ
2. 按 κ 值排序：κ ≥ 0.85 为确认 L1、0.70 ≤ κ < 0.85 为观察区、κ < 0.70 为待定（可能需降级至 L2）
3. 对每项任务，计算 3 位人类评审者之间的 κ 作为基线（人类自身的信度）
4. 对"逻辑断裂检测"子任务单独进行：
   a. 配对 t 检验，比较规则匹配组与 RST 辅助组在召回率上的差异
   b. 分析 RST 辅助组的假阳性率（误将刻意偏离检测为断裂）
   c. 计算两组的精确率与人类认可率
5. 对 RST 能检测但规则匹配遗漏的断裂，归类为新的 L2 任务候选

## 成功标准

- 所有 L1 任务的 AI-人类 κ ≥ 0.85 → 分类成立
- 存在任何 L1 任务的 κ < 0.70 → 该任务降级至 L2，调整分类
- RST 辅助组的召回率显著高于规则匹配组（p < 0.05，单侧）
- RST 辅助组的精确率不低于规则匹配组
