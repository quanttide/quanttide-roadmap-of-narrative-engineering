# E3 — 分类系统质量校准

## 假设

1. "表层意象识别"和"情绪倾向标签"的 AI-人类一致率（κ）显著高于其他 L2 任务，与 L1 分布重叠，可升入 L1。
2. "情感冲击力"和"整体审美判断"的 AI 输出与人类判断无显著相关性（Spearman ρ < 0.3），确认保留在 L3。
3. L1 任务的重测信度（ICC）≥ 0.85，L2 任务的重测信度 ≥ 0.70。
4. AI 评审与人类评审的效度相关系数在 L1 任务上 ≥ 0.80，在 L2 任务上 ≥ 0.50。

## 材料

职场言情系列 14 篇成稿（与 E1 同批）。其中 5 篇作为重测信度测试集，由系统从 14 篇中随机抽取。

## 评审者

复用 E1 的 3 位评审者。L3 任务的"情感冲击力"和"整体审美判断"增加 2 位大众读者评审者，以提供更接近愿景中"读者群体"视角的参照。

## 流程

实验分为两个阶段：

### 阶段 A — L2/L3 边界校准

1. **边界分析**：从 E1 结果中提取全部 7 项 L1 任务的 κ 值，新增"表层意象识别"和"情绪倾向标签"两项 L2 边缘任务的 AI-人类 κ 值（如 E1 未覆盖此两项标注，补充一轮评审）
2. **L3 对照实验**：对"情感冲击力"和"整体审美判断"两项 L3 边缘任务执行对照：
   - AI 对 14 篇输出"情感冲击力"评分（1–7 点量表）和"整体审美判断"（A/A-/B）
   - 3 位评审者 + 2 位大众读者对同一材料执行相同判断
3. **汇总**：将 E1 的 L1 κ 值、新增 L2 κ 值、L3 Spearman ρ 值统一排序

### 阶段 B — 重测信度与效度验证

1. **重测信度**：
   - 在 3 个不同时间点（间隔 ≥ 24 小时），AI 对 5 篇测试集执行同一组 L1/L2 任务
   - 计算逐项任务在 3 次测量间的组内相关系数（ICC(2,1)），附带 95% 置信区间
2. **评分者间一致性**：
   - AI 模拟 3 种不同人格模式（高开放性/低开放性/高共情），对同一 5 篇测试集执行 L2 任务
   - 计算 3 种人格模式间的评分者间信度
3. **效度验证**：
   - 以阶段 A 中收集的人类评审判断为效标（含 3 位评审者 + 2 位大众读者）
   - 计算 AI 判断与人类判断的 Spearman ρ
   - 分层报告：AI vs 评审者、AI vs 大众读者

### 旁路分析 — 人格模式模拟

阶段 B 第 2 步的人格模式模拟作为旁路分析独立运行，不参与边界校准决策。产出仅用于评估"AI 模拟视角"的稳定性和可行性，为产品中的"模拟镜像"功能提供数据支撑。

## 变量

### 阶段 A

- 自变量：任务类型（L1: 7 项 + L2 边缘: 2 项 + L3 边缘: 2 项 = 11 个水平）
- 因变量：一致率（二值任务用 Cohen's κ，连续/有序任务用 Spearman ρ）

### 阶段 B

- 因变量：ICC、评分者间信度、效度相关系数

## 分析方案

1. **边界校准**：
   - 将 E1 全部 L1 κ 值 + 新增 L2 κ 值排序，观察 L2 任务 κ 值是否与 L1 分布重叠
   - 对"情感冲击力"和"整体审美判断"：如 Spearman ρ < 0.3，确认 L3 分类
   - 输出经实证校准的 L1/L2/L3 分类总表（覆盖全部预估 15–19 项任务）
2. **信度剖面**：
   - 每项任务输出"信度剖面"，格式示例：
     ```
     L1 · 逻辑断裂检测 · 重测信度 0.92 [0.85, 0.96] · 效度 0.88
     L2 · 风格一致性   · 重测信度 0.73 [0.62, 0.81] · 效度 0.61
     ```
3. **自动降级规则**：
   - 重测信度 ICC < 0.70 的任务：L1 → L2，L2 → 警告标注
   - 效度 ρ < 0.30 的任务：建议移入 L3
4. **校准输出**：一份"分类系统质量报告"，每条任务附带"κ/ρ → ICC → 效度"的完整信度剖面

## 成功标准

- 校准后的分类表有逐项的实证 κ/ρ 值
- 每项评审任务附重测信度和效度指标
- 信度过低的任务自动降级规则已建立并可执行
- 分类表可输出为正式文档

## 依赖

- 前置依赖：E1、E2
- 旁路输入：E1 评审者数据、E2 异常分类数据
- 后续实验：无（E3 是实验序列的终点）
- 劳动力需求：复用 E1 评审者 + 2 位大众读者（L3 对照实验专用）
