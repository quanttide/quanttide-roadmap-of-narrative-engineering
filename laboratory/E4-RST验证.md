# E4 — 修辞结构理论验证

## 假设

RST 辅助的逻辑断裂检测在召回率上显著高于当前 L1 的模式匹配方法。

## 材料

从 14 篇中选取 5 篇包含明确逻辑断裂和有意结构跳跃的篇目（建议：2.1 展会再遇、4.3 互相问早、6.2 海边散步、9.1 家里吃火锅、10.3 阳台看星星）。

## 流程

1. **RST 标注**：对 5 篇进行 RST 关系标注（核-卫星结构关系，如证据-主张、背景-叙述、因果、时序、对比）
2. **对照组**：现有 L1 模式匹配（关键词/连接词触发）
3. **实验组**：RST 辅助（检测 RST 关系链中的缺失/冲突，如"标记为因果但缺乏前提"）
4. **地面真值**：2 位语言学背景评审者独立标注真实断裂位置

## 变量

- 自变量：检测方法（模式匹配 vs RST 辅助，2 个水平）
- 因变量：
  - 召回率（正确检测的断裂数 / 地面真值断裂总数）
  - 精确率（检测为断裂的位置中实际断裂的比例）
  - 人类认可率（被检测出的断裂中人类评审认可的比例）

## 分析方案

1. 配对 t 检验，比较两组在召回率上的差异
2. 分析 RST 辅助组的假阳性率（误将刻意偏离检测为断裂）
3. 对 RST 能检测但模式匹配遗漏的断裂，归类为新的 L2 任务候选

## 成功标准

- RST 辅助组的召回率显著高于对照组（p < 0.05，单侧）
- RST 辅助组的精确率不低于对照组

## 依赖

- 前置依赖：E1（需已有 L1 逻辑断裂检测的基线数据）
- 后续实验：E5（RST 的偏离检测能力可补充到 E5）
