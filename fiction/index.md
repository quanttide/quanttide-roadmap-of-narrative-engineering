# 小说创作蓝图

## 当前能力

平台已建立从素材到成稿的完整小说创作管线。

### 作者可用的工具

| 命令 | 用途 | 示例 |
|------|------|------|
| `narrative-cli extract` | 从场景提取母题，看看自己用了什么模式 | `extract --scene 1_1_咖啡厅重逢.md --motif-profile motif.yaml` |
| `narrative-cli review` | 用 style.yaml 评审场景，诊断风格弱点 | `review --scene draft.md -S style.yaml` |
| `narrative-cli review -M` | 风格评审 + 交叉诊断（弱维度→缺失母题） | `review --scene draft.md -S style.yaml -M motif.yaml` |
| `narrative-cli inspire` | 分析母题缝隙，生成 6 方向改进建议 | `inspire --scene draft.md -M motif.yaml` |

### 模型文件

| 文件 | 回答的问题 | 都市言情实例 |
|------|-----------|-------------|
| `style.yaml` | 怎么写算好 | 11 维度：克制浪漫，情感表达在动作不在台词 |
| `motif.yaml` | 用什么叙事模式 | 5 母题：十年、手势、雨、孤独、歌声 |
| `story.yaml` | 讲了一个什么故事 | 14 章场景 + 2 人物：迟到的双向奔赴 |

## 创作工作流

### 1. 了解自己 — 提取母题

写完一个场景后，跑 `extract` 看看自己实际用了什么母题。可能发现"原来我一直在写这个"——p05 证明单篇场景的信号已经足够。

```
extract → 发现用了"手势"和"雨"，漏了"十年"
```

### 2. 诊断问题 — 风格评审

跑 `review` 看看哪些维度执行不到位。

```
review → 情感表达 5/10，时代质感 6/10
```

### 3. 找到根因 — 交叉诊断

跑 `review -M` 建立"弱维度↔缺失母题"的映射。

```
review -M → 情感表达偏低 ↔ 缺手势母题（手势=动作先于语言）
             时代质感偏低 ↔ 缺歌声母题（特定歌曲标记情感）
```

### 4. 获得建议 — 母题缝隙分析

跑 `inspire` 获得 6 个方向的改进建议。不是所有建议都要听——对低 weight 母题，"克制"可能是最优解。

```
inspire → [增强] 在第3段加入递毛巾的动作序列
          [借用] 跨作品借校园版的"纸巾擦眼泪"变体
          [克制] 歌声 weight=5，十年母题已经够重，不加更好
```

### 5. 迭代 — 重写 + 重新评审

根据建议修改场景，重新跑 `review` 验证改进。

```
修改后 → review → 情感表达 5→7，时代质感 6→8
```

| "想保持风格一致" | style.yaml 作为审美配置文件 | p09 |
